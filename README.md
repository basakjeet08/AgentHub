# AgentHub

A TUI hub for managing coding-agent sessions.

Base project init: dependencies and package entry point only.

## Requires

- Python >= 3.13
- pyenv environment `agenthub` (see `.python-version`)

## Install

```fish
python -m pip install -e ".[dev]"
```

## Run

```fish
agenthub
```

or

```fish
python -m agenthub
```
